# 🚌 Atlas BusX - Front-End Case

Bu proje, **Atlas Yazılım** için hazırlanan Front-End değerlendirme projesidir.  
React, TypeScript, Vite ve TailwindCSS kullanılarak geliştirilmiştir.

---

## 🚀 Teknolojiler
- ⚛️ **React 18** – Bileşen tabanlı mimari  
- ⚡ **Vite** – Hızlı geliştirme ortamı  
- 💅 **Tailwind CSS** – Modern UI tasarımı  
- 🧩 **TypeScript** – Tip güvenliği  
- 🔄 **Mock API** – Gerçekçi veri akışı simülasyonu

---

## 🧠 Proje Özeti
Kullanıcılar, **otobüs seferlerini arayabilir**, kalkış-varış şehirlerini seçebilir ve uygun tarihleri filtreleyebilir.  
Tasarımda sade, modern ve responsive (mobil uyumlu) bir yapı benimsenmiştir.

### Özellikler:
- Sefer arama formu  
- Mock verilerle çalışan dinamik sonuç ekranı  
- Koltuk seçimi için hazır veri yapısı (mock JSON)  
- Dark/Light tema desteği  
- Tailwind + custom stil kombinasyonu

---

## ⚙️ Kurulum
Projeyi yerel ortamında çalıştırmak için:

```bash
# 1. Depoyu klonla
git clone https://github.com/SelcanTopakli/atlas-busx-case.git

# 2. Klasöre gir
cd atlas-busx-case

# 3. Bağımlılıkları yükle
npm install

# 4. Uygulamayı başlat
npm run dev
